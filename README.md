# IPv4 Subnet Conversion

A C++ command-line tool that analyzes IPv4 addresses, determines network classes, converts IP/subnet masks to binary, and calculates host capacity.

## Features
* **Validation:** Checks IPv4 address formatting and octet ranges.
* **Network Class:** Detects Class A, B, C, D, or E networks.
* **Type Identification:** Identifies Public, Private, or Loopback addresses.
* **Binary Conversion:** Displays binary representations of IP and Subnet Masks.
* **Host Calculation:** Computes total usable IP addresses and host bits.
